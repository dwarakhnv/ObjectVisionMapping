How to connect

    
    
      
  • Detection starts when an app connects and stops by itself  s after the last request, so nothing runs (or uses the computer) while nobody is connected. The first answer after a pause may have no objects yet.
    • 
      
  • Send the key in a header, Authorization: Bearer <key>. Browsers' EventSource can't send headers, so it can use ?token=<key> instead.
    • 
      
  • Add ?classes=person,car to narrow the results further, within what the key allows.
    • 
      
  • Other computers must be on the same network, or reach this one through a VPN or tunnel. Windows may ask to allow Python through the firewall.
